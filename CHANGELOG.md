# Historial de cambios

Cada versión es un commit con su etiqueta (`v1`, `v2`, …).

## Cómo volver a una versión

```bash
git tag                     # ver versiones
git checkout v1             # ver el sitio como estaba en v1 (solo lectura)
git checkout main           # regresar a la última versión
git diff v1 v2 --stat       # qué archivos cambiaron entre versiones
git switch -c rescate-v1 v1 # crear una rama a partir de una versión para retomarla
```
